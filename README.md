## ftml

A Rust library to parse Wikidot text ("Wikitext") into an abstract syntax tree (AST), with HTML and text renderers.

This repository is Rokurolize's fork of [scpwiki/ftml](https://github.com/scpwiki/ftml). Development and pull requests land here, not upstream; fork versioning and sync policy are in [`docs/ForkVersioning.md`](docs/ForkVersioning.md).
